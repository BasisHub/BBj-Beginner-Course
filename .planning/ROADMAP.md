# Roadmap: BBj Beginner Tutorial

## Overview

Transform the existing 5-section flat documentation site into a structured 12-chapter course that gets experienced developers productive in BBj. The journey moves from infrastructure parity with the DWC tutorial, through content reorganization and existing content improvement, into 7 new chapters covering the daily-use gaps (error handling, strings, collections, database, Java interop, events, debugging), and finishes with the differentiators that make this tutorial uniquely valuable: legacy code reading training, generation mapping, and cross-language translation tables.

- [ ] **Phase 6: Differentiators and Quality** - Legacy code sidebars, generation mapping, translation tables, exercises, and code quality

### Phase 4: Core Language Chapters
**Goal**: Readers can handle errors, manipulate strings and numbers, and work with collections in BBj -- the three most frequently needed capabilities after basic syntax
**Depends on**: Phase 2 (needs chapter directory structure and samples/ directory)
**Requirements**: CONT-05, CONT-06, CONT-07
**Success Criteria** (what must be TRUE):
  1. A reader can look up SETERR, THROW, ON ERR, and try/catch patterns with working examples that run in BBj IDE
  2. A reader can find and use the daily string/numeric functions (LEN, MID, POS, CVS, STR, NUM, MASK) with copy-paste examples
  3. A reader can create, populate, iterate, and convert between BBjVector, BBjHashMap, and Java collections
  4. Each chapter has "Reading Legacy Code" callouts showing how the same operation looked in older BBj generations

### Phase 5: Data and Application Chapters
**Goal**: Readers can access databases via SQL, call Java from BBj, handle events systematically, and debug their programs -- completing the full skill set for independent BBj development
**Depends on**: Phase 4 (database chapter needs error handling and collections; Java interop needs OOP from Phase 3)
**Requirements**: CONT-08, CONT-09, CONT-10, CONT-11
**Success Criteria** (what must be TRUE):
  1. A reader can open a SQL connection, prepare and execute queries, and iterate a BBjRecordSet using working examples
  2. A reader can call Java classes from BBj, use Java libraries, and extend Java interfaces with BBj code
  3. A reader can wire up event callbacks using setCallback, handle common event types, and understand the process_events loop
  4. A reader can use the BBj IDE debugger, interpret BEM error information, look up common error codes, and apply PRINT-based debugging
  5. Each chapter has corresponding .bbj sample files in the samples/ directory that run without modification

### Phase 6: Differentiators and Quality
**Goal**: The tutorial delivers unique value no other BBj resource provides -- systematic legacy code reading training, generation mapping, cross-language translation -- and every chapter meets quality standards for exercises, runnable code, link integrity, and consistent style
**Depends on**: Phase 5 (all content must exist before cross-cutting quality and differentiation work)
**Requirements**: DIFF-01, DIFF-02, DIFF-03, DIFF-04, QUAL-01, QUAL-02, QUAL-03, QUAL-04
**Success Criteria** (what must be TRUE):
  1. Every relevant chapter has a collapsible "Reading Legacy Code" sidebar showing legacy equivalents of the modern patterns taught
  2. A "Generations of BBj" reference page shows all 4 generations side-by-side with when each was common, signature syntax, and modern equivalents
  3. Each chapter that covers a concept with Java/.NET/Python equivalents has a translation table
  4. Every chapter has structured exercises with clear objectives that a reader can complete
  5. Every code example across the entire site is copy-paste runnable in BBj IDE, all external links work, and code style is consistent
