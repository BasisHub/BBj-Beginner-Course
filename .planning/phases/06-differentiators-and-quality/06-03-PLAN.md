Code style guide (from research, normalize all code to match):
- `rem` lowercase for inline comments; `REM` uppercase only in sample file section dividers
- 4-space indentation inside methods, handlers, loops
- One blank line between logical sections
- Labels lowercase: `handler:`, `done:`, `not_found:`
- SQL/file verbs uppercase: SQLOPEN, SQLPREP, SQLFETCH, DIM, OPEN, READ RECORD, WRITE RECORD
- Flow control lowercase: seterr, for, while, if, print, release
- Class/method keywords lowercase: class, classend, method, methodend, field
- `print` lowercase in inline examples (uppercase PRINT only in SQL/file-IO verb contexts)
- Sample file headers use `rem === Title ===` format (not JavaDoc style)
</context>
