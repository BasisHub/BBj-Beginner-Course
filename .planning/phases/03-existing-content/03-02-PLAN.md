Frontmatter: `sidebar_position: 2`, `title: "Using Java Classes from BBj"`

Content sections:
1. **Opening:** One of BBj's core strengths is direct access to any Java class. BBj runs on the JVM, and Java interop is a daily-use capability, not an edge case.
2. **Importing Java Classes** — The `use` verb and direct fully-qualified instantiation. Show both patterns.
3. **HashMap and Iterator** — Use the HashMap/Iterator example from RESEARCH.md. Walk through the pattern: create, populate, iterate.

6. **Limitations to Know:**
   - No generics syntax — `HashMap` not `HashMap<String, String>`. Types are resolved at runtime.
   - BBj interprets Java objects at runtime — no compile-time type checking across the boundary.
   - Java exceptions become BBj errors — handle with SETERR or ERR= branching.
7. **Further Reading** — Link to [Types in BBj](https://documentation.basis.cloud/BASISHelp/WebHelp/usr/BBj_Enhancements/types_in_bbj.htm)
