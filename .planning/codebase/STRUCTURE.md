## Directory Purposes

**docs/**
- Purpose: Tutorial content source (single source of truth)
- Contains: Markdown files organized by topic/section
- Key files: Each section has one `index.md` containing all content for that topic
- Note: Flat structure within each directory (no nested subdirectories)

**src/css/**
- Purpose: Global styling and theme customization
- Contains: Custom CSS that overrides Docusaurus/Infima defaults
- Key files: `custom.css` - defines green/teal color scheme for light and dark modes

**static/img/**
- Purpose: Branding and course assets
- Contains: Logo, favicon, social card image, and course-related graphics
- Note: Files are copied to output verbatim; Docusaurus does not process or optimize

**build/**
- Purpose: Production-ready static website (output artifact)
- Contains: Generated HTML pages, bundled assets, and metadata
- Generated: Yes (output of `yarn build`)
- Committed: No (in .gitignore)

**.docusaurus/**
- Purpose: Docusaurus internal cache and metadata
- Generated: Yes (created during `yarn start` or `yarn build`)
- Committed: No (in .gitignore)

**.github/workflows/**
- Purpose: Continuous integration and deployment automation
- Contains: GitHub Actions workflow definitions
- Key files: `deploy.yml` - triggers build on master push and deploys to GitHub Pages

## Naming Conventions

**Files:**
- Markdown docs: `index.md` (one per section, not nested)
- Config files: `docusaurus.config.js`, `sidebars.js` (camelCase)
- CSS: `custom.css` (kebab-case)
- GitHub Actions: `deploy.yml` (kebab-case, YAML format)

**Directories:**
- Content sections: `introduction/`, `getting-started/`, `object-oriented/`, `file-io/`, `web-development/` (kebab-case)
- Framework dirs: `docs/`, `src/`, `static/`, `build/`, `.github/` (lowercase)
- Assets: `img/`, `css/` (lowercase, functional names)

## Where to Add New Code

**New Tutorial Section:**
- Create directory: `docs/[section-name]/` (kebab-case)
- Implementation: Add `docs/[section-name]/index.md` with YAML frontmatter
- Register in navigation: Add entry to `sidebars.js` with `type: 'doc'` and matching id
- Example structure:
  ```markdown
  ---
  slug: /[section-name]
  ---
  # [Section Title]
  [Content here]
  ```

**New Styling or Theme Changes:**
- Location: Modify `src/css/custom.css`
- Approach: Override CSS variables (e.g., `--ifm-color-primary`) rather than adding new selectors
- For major theme changes: Update `docusaurus.config.js` theme section

**New Site Navigation Links:**
- Navbar links: Update `docusaurus.config.js` → `themeConfig.navbar.items`
- Footer links: Update `docusaurus.config.js` → `themeConfig.footer.links`
- Doc sidebar: Update `sidebars.js` → `tutorialSidebar` array

**New Static Assets (images, favicons, etc.):**
- Location: `static/img/` (or subdirectory within)
- Reference in Markdown: Use relative paths like `![alt text](../../static/img/filename.png)` or `/img/filename.png` after build

## Special Directories

**.docusaurus/**
- Purpose: Docusaurus build cache and generated metadata
- Generated: Yes (automatically during dev server or build)
- Committed: No (in .gitignore)
- Do not edit manually

**build/**
- Purpose: Production output - ready to deploy to GitHub Pages
- Generated: Yes (via `yarn build`)
- Committed: No (in .gitignore)
- Contents: Static HTML, CSS bundles, JS bundles, optimized assets

**node_modules/**
- Purpose: Installed npm dependencies
- Generated: Yes (via `yarn` or `npm install`)
- Committed: No (in .gitignore)
- Do not edit manually

## Routing and URL Structure

**Route Mapping:**
- `/` → `docs/introduction/index.md`
- `/getting-started` → `docs/getting-started/index.md`
- `/object-oriented` → `docs/object-oriented/index.md`
- `/file-io` → `docs/file-io/index.md`
- `/web-development` → `docs/web-development/index.md`

**Route Determination:**
- YAML frontmatter `slug` field overrides default path-based routing
- If no slug specified, route = `docs/{directory-name}/`
- Trailing slash disabled (via `trailingSlash: false` in config)

## Configuration File Purposes

**docusaurus.config.js:**
- Site metadata (title, URL, branding)
- Navigation structure (navbar items, footer links)
- Plugin configuration (docs plugin routing)
- Theme configuration (colors, syntax highlighting, dark mode)
- Deployment settings (baseUrl for GitHub Pages subpath)

**sidebars.js:**
- Defines tutorial navigation order
- Links doc file IDs to display labels
- Enables automatic prev/next navigation between pages
- Creates sidebar component for each page

**package.json:**
- Dependency versions (Docusaurus 3.9.2, React 19, etc.)
- Build scripts (start, build, deploy, serve)
- Project metadata (name, version)
