# Milestone v1.0: Complete Course

**Status:** SHIPPED 2026-02-01
**Phases:** 1-6
**Total Plans:** 20

## Overview

Transform the existing 5-section flat documentation site into a structured 12-chapter course that gets experienced developers productive in BBj. The journey moves from infrastructure parity with the DWC tutorial, through content reorganization and existing content improvement, into 7 new chapters covering the daily-use gaps (error handling, strings, collections, database, Java interop, events, debugging), and finishes with the differentiators that make this tutorial uniquely valuable: legacy code reading training, generation mapping, and cross-language translation tables.

## Milestone Summary

**Key Decisions:**
- Teach modern BBj, explain legacy as context (legacy subpages + generations page)
- No try/catch in BBj — trap-and-branch model exclusively (SETERR, ERR=, THROW)
- SQLFETCH as primary SQL access pattern (BBjRecordSet for GUI only)
- setCallback as sole recommended event pattern
- org.json for JSON parsing (bundled with BBj 25.x)
- Exercises deferred to future milestone by user decision

**Issues Resolved:**
- Broken documentation.basis.cloud links (updated to index pages)
- OOP chapter had incorrect try/catch examples (corrected to ERR=/SETERR)
