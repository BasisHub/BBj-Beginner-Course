# Using Java Classes from BBj

Java interop is covered in detail in the dedicated [Java Interop chapter](/java-interop).

That chapter covers:
- **Basics** -- importing classes, creating objects, calling methods, type mapping
- **Advanced patterns** -- implementing interfaces, handling exceptions, classpath configuration
- **Practical libraries** -- JSON, HTTP requests, Base64, hashing, UUID generation
